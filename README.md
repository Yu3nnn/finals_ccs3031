------------------------------------------------------------------------------------------------------------------------

1. Project Overview
The objective of this final project is to simulate a real-world software development engagement wherein
each development team will design and develop a Single-Page Application (SPA) website for an actual
local business or establishment, or university recognized organization located either inside or outside the
university vicinity.
Each group shall function as a software development company contracted by a client. Therefore,
professionalism, usability, quality, completeness, and attention to detail are expected throughout the
project.
This project is intended to develop your skills in:
• Client requirement analysis
• User Interface (UI) Design
• User Experience (UX)
• Vue.js development
• Component-based architecture
• Routing
• Responsive web design
• Team collaboration

------------------------------------------------------------------------------------------------------------------------

2. Group Composition
Each group shall consist of exactly three (3) members. These members may come from different
sections under the same instruction.
Every member must actively contribute to the project. Unequal participation may affect individual grades.
Each member should have developed at least 1 view/page and 2 sections by the end of the project
development. The more component a member had developed, the higher possibility he/she will have
higher score for this project.
After the presentation, additional tasks will be required for each group member to validate his/her
contribution in the project development in support for the individual scoring application.

------------------------------------------------------------------------------------------------------------------------


3. Client Selection
Each group must select one (1) real local business or establishment, or a university recognized
organization.
Examples include:
• Restaurants
• Coffee Shops
• Bakeries
• Grocery Stores / convenient store
• Pharmacies
• Laundry Shops
• Printing Shops
• Computer Shops
• Dental Clinics
• Medical Clinics
• Gyms
• Salons
• Barber Shops
• Bookstores
• School/Student Organizations
The selected establishment must be located:
• inside the university
• outside/around the university
Groups are encouraged to interview the business owner or organization leaders or gather accurate
information whenever possible. It is the prerogative of the group on how to acquire product images or any
materials related to the client or the business, which will be used for this project.

------------------------------------------------------------------------------------------------------------------------

4. Project Requirements
Develop a Single-Page Application (SPA) using Vue.js.
- The website must contain at least five (5) different views/pages. It is the prerogative of the
group what views/pages to include. So long as these will make the website as informative as
possible.
- Three (3) of the views/pages should have multiple sections, depending on the layout you want to
implement.
- Should rely on scripts in routing the sections or views and not just HTML.
- Should also implement proper code structure including using of multiple Vue files and proper file
organization.
- Each section should have a smooth scrolling behavior when redirected from another section
within the same view/page.
- The website should also be responsive to mobile devices.
